Import ALL Agent Skills from a public GitHub repository supplied by the user in this task. Never ask which skills to choose.
A bare GitHub skill repository URL sent directly by the user counts as a request to import all its skills. Also use this when the user asks to import/install/use the repository skills. Questions about feasibility, safety or code review alone are not import requests.
1. Call action=prepare with repository_url and quote (the user's own import request). This downloads an immutable revision, discovers every SKILL.md, and prepares English adaptations using the tools actually available in this task. Nothing is saved or executed yet.
2. Tell the user the proposed substitutions and material limitations BEFORE installing or using any adapted workflow. Explain which skills are ready/adapted and which require setup or are unsupported. Do not claim they have been tested.
3. Call action=install with the returned plan_id, the SAME repository_url, and the user's quote. Include the substitutions and limitations in reason; it is shown to the user before installation and is required for install. The user's import request authorizes saving the whole repository; do not ask them to choose skills or repeat approval for equivalent substitutions. Missing credentials, payments, permissions or a meaningful change of purpose still require user input before use.
4. Report the actual saved/failed counts and any unresolved requirements. Ready/adapted skills start as trials; setup/unsupported skills are saved disabled. All saved skills are visible in Settings > Memory & skills. Only saved=true means that skill was saved.
Do not run downloaded scripts, install dependencies, request secrets or connect accounts during import. The source and notices are retained as references. On later use, explain the saved substitutions before acting and check that required tools and connections are available. Re-import to reassess after setup; never silently enable blocked skills.
